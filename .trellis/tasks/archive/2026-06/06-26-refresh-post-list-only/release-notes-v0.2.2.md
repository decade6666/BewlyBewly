## v0.2.2

### ✨ 新特性

- **帖子列表原地刷新**：在 linux.do 帖子列表页（最新 / 热门 / 精华 / 分类等），点击右下角浮动「刷新」按钮不再整页重载，而是只刷新帖子列表——URL 不变、不白屏、保留扩展注入的增强（标签、隐藏置顶等），刷新后回到列表顶部。
  - 优先点击 Discourse「N 条新帖」横幅，否则回退点击当前激活的导航标签，触发列表原地刷新；在非列表页或未命中刷新入口时，仍回退为整页重载，保证按钮始终可用。

### 🧩 其他

- 刷新决策逻辑抽离为纯函数并补充单元测试；Discourse 选择器整理为带来源注释的命名常量。

---

> 安装：Chrome / Edge 使用 `extension.zip`，Firefox 使用 `extension-firefox.zip`。
